# README.md

## Project Overview

This is a personal portfolio website for Sora Takashima, a machine learning engineer and researcher. The site serves as a digital resume showcasing professional experience, research publications, educational background, and personal projects. It includes an interactive JavaScript game as a hidden unique portfolio feature.

## Architecture

**Static Website Structure:**
- `index_final_accurate.html` - Main portfolio page with embedded styling and JavaScript
- `static/` - All static assets (CSS, JavaScript, images)
  - `css/` - Stylesheets including PhotoSwipe gallery and main styles
  - `js/` - JavaScript libraries and main game implementation
  - `img/` - Images organized by section (about, contact, education, experience, etc.)

**Core Components:**
- **Portfolio Sections**: Experience, Research, Education, Works, Contact
- **Hidden Interactive Game**: Browser-based game as a hidden unique portfolio feature
- **Responsive Design**: CSS media queries for mobile/desktop compatibility
- **Multi-language Support**: Japanese/English toggle functionality

## Development Workflow

**No Build Process Required:**
This is a static website that runs directly in browsers without compilation or build steps.

**Available Versions:**
- `index.html` - Original portfolio design (legacy)
- `index_modern_XXX.html` - Modern portfolio design with 2025 trends (trial version)
- `index_final_accurate.html` - **Latest version of modern portfolio design**

**Testing:**
- Open `index_XXX.html` directly in a web browser
- No automated testing framework is configured
- Manual testing across different browsers and devices recommended
- Modern version includes responsive design testing utilities

**Deployment:**
- Static files can be deployed to any web server
- Currently hosted on GitHub Pages at: `https://masora1030.github.io/soraemonpockt/`
- To deploy fixed modern version: rename `index_XXX.html` to `index.html`
